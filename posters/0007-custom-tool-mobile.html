LESSON 0007 · 工具协议化 制造通行副卡

亲手造卡：从网页点选到专属 Tool

把反复肉身登录的后台操作，降维封装为 Agent 能够自主调用的免密工具。

1. F12 抓包：将网页降维为 cURL 协议层脱水
网页上的五级菜单和按钮，本质上只是一个带 Cookie/Header 的 HTTP 请求。按 F12 复制为 cURL 命令。
curl -X POST https://api.admin/approve -H "Cookie: session=..."
2. 凭证解耦：把死数据变成脚本 参数化
写一个 15 行的 Python/Shell 小脚本，把动态参数（如 `user_id`）作为命令行入参，凭据由本地环境统一托管。
python approve.py --user 10024 --role developer
3. 声明契约：告诉 Agent 怎么用 Tool 契约
用一段标准 JSON 告诉模型：“当你需要审批权限时，调用 approve_perm(userId)”，无需向人类求助！
🔑 绝密心法：模型不需要“看见网页”
让 Agent 操纵浏览器去点按钮，是效率最低、最容易被验证码卡死的做法！直接调用底层 API 接口工具，速度提升 50 倍，成功率从 40% 暴涨至 100%！
