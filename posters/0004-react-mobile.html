ReAct 状态机：Agent 自治循环

以 Android 事件循环视角，解构智能体如何连续决策与执行。

🎯 用户目标 (Goal: 审批权限并同步后台)
↓
🧠 1. THOUGHT (认知推导) LLM 内核
基于目标分析现状，在工具库中匹配最优算子：
"缺少Token凭证，首步应调用 auth_token 工具获取鉴权..."
↓ 生成 ToolCall JSON
⚡ 2. ACTION (动作下发) Harness 装具
拦截 Tool 调用，从本地 Keychain 自动代填凭据并执行：
call_tool("fetch_token", { scope: "admin" })
↓ 捕获执行真实 stdout
👁️ 3. OBSERVATION (环境观察) 结果入队
捕获底层物理真实反馈，无损追加回上下文：
{"status": "ok", "token": "eyJh...89", "code": 200}
↓ 状态判定
❓ 任务是否完全闭环？
❌ 未达成 带上 Observation 回流 ➔
✓ 交付结果
🚨 死锁打杂陷阱 (ReAct Infinite Loop)
如果底层返回 403/反爬且未说明根因，Agent 就会在缺乏新信息的情况下反复猜疑重试，把你变成疯狂处理验证码的“肉身打杂工”！
