# 0011: 进入核心破局课——工具协议化与通行副卡制造

学习者决定先跳过底层的源码汉化改造，聚焦核心能力跃迁。
正式开启 Lesson 0007：《亲手造卡：从网页点选到专属 Tool》。

## 本课目标
彻底破除对“无头浏览器操作网页”的低效迷信，掌握高阶 Agent 架构师的标准操作：
1. **F12 抓包降维**：将混乱庞杂的网页 DOM 剥离，只保留干净的底层 HTTP/cURL 接口。
2. **凭据解耦与参数化**：将固定数据封装为接收入参的小脚本，Token 由环境托管。
3. **声明 Tool Schema**：通过标准的 JSON 契约暴露给 Agent，实现全自动静默调用。
