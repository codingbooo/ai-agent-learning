# 0006: 诊断到认知超载（Cognitive Overload）—— 启动降维梯子

在推进 Lesson 0004（ReAct 状态机与事件循环）时，用户反馈“这节课对我来说有点难”。

## 认知诊断（Diagnosis）
1. 一次性引入了多层抽象概念：ReAct 循环（Thought/Action/Observation）、状态机判定（Is Goal Met）、Harness 拦截、与 Android 底层 Looper/MessageQueue 的跨域映射。
2. 抽象概念叠加导致工作记忆（Working Memory）超载，脱离了“最近发展区（ZPD）”。
3. 学习者需要从最真实、最具体、最切身的具体生活/工作场景切入，用“现实排障”反推机制，而非先看复杂的宏观拓扑。

## 教学纠偏策略（Pedagogical Adjustment）
- 暂停宏观理论灌输，撤掉复杂术语。
- 采用苏格拉底式极简降维场景：拿一个具体的“小助理去办公室盖章”或“点外卖”的现实生活隐喻，拆解它的三步动作。
- 梯子搭建：先理解日常动作，再映射到 Agent 为什么会卡住。
