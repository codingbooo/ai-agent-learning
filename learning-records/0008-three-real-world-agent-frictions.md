# 0008: 学习者三大核心工程困境（真实世界摩擦）

在完成前四课基础原理与生活化隐喻内化后，学习者精准提炼出了阻碍其日常高效协作的 3 个最真实物理痛点：

1. **后台权限控制（Auth & RBAC）**：Agent 频繁卡在内网/平台鉴权点，需要人介入。
2. **高危命令黑盒审查恐惧（Command Uncertainty）**：Agent 请求审批终端高危指令，但人无法迅速评估其破坏性、真实意图与系统影响面。
3. **模型过敏拒答（Safety Refusal / Alignment Friction）**：模型在处理正常运维/抓取合规操作时，因基座对齐过度敏感而拒答或拒绝执行。

## 战术价值
这 3 个点代表了从“初级开发者”到“工业级 Agent 操控者”的真正核心技能树（权限托管、意图透视、对齐越狱与框架引导）。将这 3 点设计为专属实战解题专题。
